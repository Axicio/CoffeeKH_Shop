# Coffee Shop KH

A demo coffee shop website built with HTML, Bootstrap and JavaScript. Open `index.html` in a browser to run it; there is no build step.

**This is a demo.** It takes no real orders or payments. Orders and bookings are saved only in the visitor's own browser, and the card details are fixed test values. Prices, opening hours and the phone number are placeholders.

## Features

- Menu with search, categories and drink options
- Cart and demo checkout with a receipt
- Table booking and order history
- Khmer and English
- Banner slideshow and opening hours status
